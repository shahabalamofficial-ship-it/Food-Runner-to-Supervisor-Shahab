# Sequence of Service

This module is a learning framework. The restaurant's current written SOP and manager instructions always take priority.

## Guest journey checklist
1. **Prepare:** clean section, correct setup, station readiness.
2. **Welcome:** greet warmly using the approved restaurant greeting.
3. **First contact:** introduce yourself if appropriate; offer help without hovering.
4. **Allergy awareness:** ask and communicate allergies according to the restaurant procedure before recommending or serving.
5. **Beverages:** clarify still/sparkling and send the order through the correct system.
6. **Food order coordination:** ensure order details and modifications are accurately communicated.
7. **Delivery:** match dish to seat, announce dish name, ask permission before placing where needed.
8. **Check-back:** return at an appropriate time without interrupting conversation.
9. **Clear and reset:** follow course timing and guest cues; ask before removing anything uncertain.
10. **Farewell:** thank guests sincerely and leave the area ready for the next service.
